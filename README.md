# RaceDay System

A simple event management system for running races where Organisers can create events and Participants can enrol and track results.

## Roles

- **Organiser**: Create/manage events, add categories, record results
- **Participant**: Browse events, enrol, view results

## Tech Stack
- SQL Server
- Node.js/Express
- JWT Authentication

## Setup
1. Run SQL script in SSMS
2. `npm install`
3. `npm start`
